## 2. Style rules (all illustrated diagrams)

- **Layout:** left-to-right panels with rounded borders and a bold italic panel title (as in the sample). One idea per panel; 3–5 panels at most.
- **Icons:** one consistent open-licence icon set for everything, e.g. [Tabler Icons](https://tabler.io/icons) (MIT) or [Google Material Symbols](https://fonts.google.com/icons) (Apache 2.0). Never mix in random clipart from the web. Record the icon licence in `figures/CREDITS.md`.
- **Colour:** one palette of about 5 colours, one per layer, used everywhere (diagrams, plots, UI). It must stay readable in greyscale (Springer print may be greyscale) and colour-blind safe.
- **Arrows:** dashed arrows for data flow between steps; solid arrows inside a step; arrowheads clearly visible.
- **Text:** short labels and bullet notes (2–5 words), the same sans-serif font, at least ~7 pt at final printed size. No paragraphs inside figures.
- **Honesty:** only draw parts that exist and are tested. If something is future work, draw it dashed and grey, and label it "future". The reference paper's mistake was a figure showing "AI analysis" that was never built.

## 3. How figures are made (reproducible and editable)

- **Illustrated diagrams:** written as source files the team can edit. Either:
  - **SVG generated by a script** (`paper/figures/src/*.py`, icons embedded), or
  - **draw.io/diagrams.net** files (`.drawio`) using the chosen icon set.
- **Data plots:** matplotlib scripts reading `results/` only, styled with the shared palette (`paper/figures/style.py`).
- **Export:** vector PDF/SVG for line art; PNG at ≥ 600 dpi only if raster is unavoidable. Older Springer proceedings instructions ask for 800–1200 dpi line art and about 300 dpi for photos ([LNCS instructions](https://www.helsinki.fi/assets/drupal/2024-12/file_2_Instructions_for_proceedings_authors.pdf)); follow the chosen venue's current rules.
- **Captions:** a full sentence saying what the figure shows and what to notice; define every abbreviation.

## 4. Review checklist per figure

1. Readable when printed at column width in greyscale.
2. Same icons, colours and fonts as the other figures.
3. Every element exists in the system, or is marked future.
4. Referenced in the text before it appears.
5. Source file and generating script committed; icon credits recorded.
6. Supervisor shown a draft before final.
